Подсказки: `int x=123%10;` // x будет иметь значение 3; `int y=123/10;` // y будет иметь значение 12.

### Алгоритм решения
1. Взять модуль числа `x` (на случай отрицательного).
2. Получить последнюю цифру: `x % 10`.
3. Получить предпоследнюю цифру: `(x / 10) % 10`.

```java
public int sumLastNums(int x) {

    return last + secondLast;
}
```

```java
}
```

## Задача 2.8. Склонение слова год/года/лет
### Текст задачи
Дана сигнатура метода: `public String age(int x);`
Необходимо реализовать метод таким образом, чтобы он возвращал строку, в которой сначала будет число `x`, а затем одно из слов: `год`, `года`, `лет`.
Слово "год" добавляется, если число `x` заканчивается на 1, кроме числа 11.
Слово "года" добавляется, если число `x` заканчивается на 2, 3 или 4, кроме чисел 12, 13, 14.
Слово "лет" добавляется во всех остальных случаях.

### Алгоритм решения
1. Получить последнюю цифру числа: `x % 10`.
2. Получить последние две цифры числа: `x % 100`.
3. Если последние две цифры от 11 до 14 — выбрать слово "лет".
4. Иначе если последняя цифра равна 1 — выбрать слово "год".
5. Иначе если последняя цифра 2, 3 или 4 — выбрать слово "года".
6. Иначе — выбрать слово "лет".
7. Сконкатенировать число `x` и выбранное слово, вернуть результат.

### Код метода
```java
public String age(int x) {
    int lastDigit = x % 10;
    int lastTwoDigits = x % 100;
    String word;

    if (lastTwoDigits >= 11 && lastTwoDigits <= 14) {
        word = "лет";
    } else if (lastDigit == 1) {
        word = "год";
    } else if (lastDigit >= 2 && lastDigit <= 4) {
        word = "года";
    } else {
        word = "лет";
    }

    return x + " " + word;
}
```

## Задача 3.10. Игра Угадайка
### Текст задачи

Метод запускается до тех пор, пока пользователь не угадает число. После этого выведите на экран количество попыток, которое потребовалось пользователю, чтобы угадать число.

### Алгоритм решения
1. Сгенерировать случайное число `number` от 0 до 9 с помощью `ThreadLocalRandom`.
2. Инициализировать счётчик попыток `cnt` значением 0.
3. В бесконечном цикле:
   - Считать число `x` от пользователя.
   - Увеличить cnt на 1.
   - Если `x == number`, вывести сообщение об успехе и количество попыток, выйти из цикла.
   - Иначе вывести сообщение о неудаче и продолжить.

### Код метода

```java
        while (!scanner.hasNextInt()) {
            System.out.println("Ошибка! Нужно целое число.");
            scanner.next();

        cnt++;
        if (x == number) {
            System.out.println("Вы угадали!");
            System.out.println("Вы отгадали число за " + cnt + " попытки");
            break;
        } else {
            System.out.println("Вы не угадали, попробуйте ещё раз.");
        }
    }
}
```

### Алгоритм решения
1. Инициализировать переменную `max` первым элементом массива.
2. Пройти по всем элементам массива начиная со второго.
3. Если абсолютное значение текущего элемента больше абсолютного значения `max` — обновить `max`.

```java
    for (int i = 1; i < arr.length; i++) {

            max = arr[i];
        }
    }
    return max;
}
```

Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, который будет содержать все элементы массива `arr`, однако в позицию pos будут вставлены значения массива `ins`.

### Алгоритм решения
1. Создать новый массив `result` размером `arr.length + ins.length`.
2. Скопировать элементы массива `arr` в `result` до позиции `pos`.
3. Скопировать все элементы массива `ins` в `result` начиная с позиции `pos`.
4. Скопировать оставшиеся элементы массива `arr` (начиная с `pos`) в конец `result`.
5. Вернуть `result`.

### Код метода
```java
public int[] add(int[] arr, int[] ins, int pos) {
    int[] result = new int[arr.length + ins.length];
    for (int i = 0; i < pos; i++) {
        result[i] = arr[i];
    }
    for (int i = 0; i < ins.length; i++) {
        result[pos + i] = ins[i];
    }
    for (int i = pos; i < arr.length; i++) {
        result[pos + ins.length + (i - pos)] = arr[i];
    }
    return result;
}
```

```java
public void reverse(int[] arr) {
    for (int i = 0; i < arr.length / 2; i++) {
        int temp = arr[i];
        arr[i] = arr[arr.length - 1 - i];
        arr[arr.length - 1 - i] = temp;
    }
}
```

2. Скопировать элементы `arr1` в начало `result`.

### Код метода
```java
public int[] concat(int[] arr1, int[] arr2) {
    int[] result = new int[arr1.length + arr2.length];
    for (int i = 0; i < arr1.length; i++) {
        result[i] = arr1[i];
    }
    for (int i = 0; i < arr2.length; i++) {
        result[arr1.length + i] = arr2[i];
    }
```

1. Пройти по массиву и посчитать количество вхождений числа `x`.
2. Создать новый массив `result` размером `count`.
3. Пройти по массиву ещё раз и записать индексы вхождений в `result`.
4. Вернуть `result`.

### Код метода
```java
public int[] findAll(int[] arr, int x) {
    int count = 0;
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == x) {
            count++;
        }
    }
    int[] result = new int[count];
    int index = 0;
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == x) {
            result[index] = i;
            index++;
        }
    }
    return result;
}
```
